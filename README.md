# 📋 Réunion Residents

Générateurs d'outils pour les réunions des résidents LHSS.

## 🎯 À quoi ça sert?

Trois générateurs pour faciliter l'organisation et le suivi des réunions résidents:

### 1. 📄 Affiche Réunion
Crée une affiche personnalisée pour annoncer la réunion avec:
- Titre et date
- Thèmes du programme (avec emojis et couleurs)
- Export en PDF prêt à imprimer

### 2. 📋 Compte-Rendu
Rédige un compte-rendu structuré avec:
- Informations générales (date, résidents présents, etc.)
- Sections par thème
- Export en PDF

### 3. 📝 Fiche d'Avis
Collecte les avis des résidents avec:
- Questions structurées
- Cases à cocher pour les sujets
- Espace pour les propositions
- Export en PDF

## 🚀 Comment utiliser?

1. Accédez au site: https://voulvic.github.io/Reunion-Residents/
2. Remplissez les champs
3. Téléchargez le PDF
4. C'est prêt à imprimer et distribuer!

**Aucun compte nécessaire** - utilisez directement dans votre navigateur! 

## 📱 Navigation

Les trois pages sont facilement accessibles via les boutons de navigation en haut du site.
